# nvidia_mfg_bridge

面向 NVIDIA RTX 20 / 30 系列显卡的帧生成扩展 Mod。

> 本仓库只发布编译好的 Release，不包含源码。请到 [Releases](../../releases) 页面下载最新版本。

---

## 简介

本项目基于开源项目 [dlssg-to-fsr3](https://github.com/Nukem9/dlssg-to-fsr3)（作者 Nukem9，GPLv3）二次开发。

原始 dlssg-to-fsr3 实现的是：将 NVIDIA DLSS Frame Generation 接口转换为 AMD FSR 3 Frame Generation，让官方不支持 DLSS Frame Generation 的显卡也能用上基础的（2 倍）帧生成。

nvidia_mfg_bridge 在此基础上做了大量进一步开发：

- 支持最高 **6 倍**插帧（原版只有 2 倍）
- 大幅提升了高倍率下的运行稳定性和流畅度
- 修复了多个会导致游戏画面卡死的问题
- 整体兼容性和健壮性都有明显提升

## 支持设备

| 支持 | 不支持 |
| --- | --- |
| NVIDIA RTX 20 系列 | AMD 显卡 |
| NVIDIA RTX 30 系列 | Intel 显卡 |

## 安装方法

Release 压缩包内包含：

1. **nvngx.dll** —— 加载器，**需要你自己改名后再使用**，可以改成以下任意名称：
   `version.dll` / `winhttp.dll` / `dbghelp.dll` / `cryptsp.dll`
   推荐改成 `version.dll`，大多数游戏目录下本来没有这个文件，冲突概率低，兼容性更好。

   > 为什么不直接打包一个改好名的文件给你：压缩包里如果直接放着一个叫 `version.dll` / `winhttp.dll` 这类系统同名文件，很容易被 Chrome 等浏览器的下载安全扫描误判成病毒，导致下载被拦截或报毒。改成自己动手改名，就不会有这个问题。
2. **nvidia_mfg_bridge.dll** —— 核心功能文件，保持原文件名即可。
3. **dxgi.dll**、**libxess_fg.dll**、**libxell.dll** —— 可选 Intel XeSS 插帧功能所需的支持文件，保持原文件名即可。默认不开启时是纯透传，不影响正常使用，不需要用到 XeSS 插帧选项的话也可以不用管它们。

把改名后的加载器文件，和其余几个文件一起复制到游戏主程序所在目录（和游戏 `.exe` 同一个文件夹），启动游戏即可生效。

无需修改注册表、无需修改游戏文件、无需破解游戏。

### 卸载

删除复制进去的所有文件即可（改名后的加载器、`nvidia_mfg_bridge.dll`、`dxgi.dll`、`libxess_fg.dll`、`libxell.dll`），不会修改任何系统文件，也不会留下多余组件。

### 配置文件

`dlssg_to_fsr3.ini` 是可选配置文件，正常游玩无需修改。

- 排查兼容性问题：把 `EnableLogging` 改成 `1`，游戏目录下会生成 `dlssg_to_fsr3.log` 供参考。
- **新增** `EnableXessFrameGeneration`：开启后改用 Intel XeSS 插帧代替本 Mod 自带的 FSR3.1 插帧，最高 2 倍，仅 DX12 有效，且需要在游戏内选中"DLSS 超分辨率"才会生效；与 FSR3 插帧互斥，开启后会自动禁用 FSR3 插帧。默认关闭。

## 功能特点

**让 RTX 20 / 30 系列用上帧生成**
NVIDIA 官方没有为 RTX 20 / 30 系列开放 DLSS Frame Generation，本 Mod 通过兼容方案让这些显卡也能使用 FSR 3 Frame Generation 带来的流畅度提升。

**最高 6 倍多帧生成**
在原版 2 倍的基础上，本项目独立实现了完整的多帧生成能力，最高支持 6 倍插帧（1 张真实画面 + 5 张生成画面），插帧倍率由游戏本身向系统申请的档位决定，具体能开到多少倍以游戏内实际可选项为准。经过反复调优，目前 2 倍到 6 倍在实际游戏中的观感都已经达到非常流畅、自然的效果。

**可选 Intel XeSS 插帧模式**
除了默认的 FSR3.1 插帧方案，本项目也接入了 Intel XeSS 的插帧能力作为可选替代，最高支持 2 倍，仅 DX12 且需要游戏内启用"DLSS 超分辨率"。默认关闭，可以在配置文件里按需开启，与 FSR3 插帧互斥。

## 稳定性优化

- 修复了部分游戏在进入 / 退出过场动画时可能出现的画面卡死问题
- 修复了部分游戏在过场动画中改变分辨率（例如出现黑边）时可能出现的画面卡死问题
- 优化了 4 倍 ~ 6 倍高倍率下的运行流畅度，减少了卡顿感
- 提升了在不同游戏、不同分辨率、HDR / SDR 等环境下的整体兼容性

这些修复不需要用户做任何额外设置，更新到最新版本即可自动生效。

## 未来计划

对于 RTX 40 系列等本身已支持官方硬件帧生成（2 倍）的显卡，我们正在研究一种混合模式：更高倍率下，基础帧继续由 NVIDIA 官方硬件帧生成提供，超出官方倍率上限的部分则依旧由本 Mod 生成 —— 让这类显卡也能兼顾官方效果与更高倍率。目前该想法仍在研究评估阶段，暂无确定的上线时间。
